С чего начинаем

Что уже умеем и куда идём

В прошлой теме программа читала числа в цикле и копила сумму. Но сами числа она тут же забывала: вернуться к ним, отсортировать или найти нужное было нельзя. Сегодня программа научится хранить все значения сразу и находить нужное по номеру или по названию.

Что уже умеем

  • условия и циклы while и for;
  • накопители: сумма, счётчик, наибольшее;
  • строки: индексы, срезы, lower() и strip();
  • меню в цикле while True.

Что будем уметь через час

  • хранить много значений в списке;
  • добавлять, удалять и сортировать;
  • разбирать строку на слова;
  • хранить записи в кортежах;
  • находить значение по ключу в словаре;
  • считать, сколько раз встречается слово;
  • вести базу записей по номеру с меню.

На КР

Третья контрольная — про функции. Но функции работают с данными: со списком студентов, со словарём оценок. Поэтому сначала нужны списки и словари. Здесь из лекций 4 и 5 собрано всё, что для этого понадобится. Множества, таблицы из списков и бинарный поиск разберём после контрольной.

1

Список

Много значений по порядку

Список — это набор значений, которые хранятся по порядку под одним именем. Список пишут в квадратных скобках, значения разделяют запятыми. Каждое значение называется элементом. Тип списка — list.

Всё знакомое по строкам работает и здесь: индексы с нуля, отрицательные индексы, срезы, len(), оператор in, циклы. Есть и главное отличие: список изменяемый. Его элемент можно заменить.

Важно

В списке могут лежать значения любых типов, даже вперемешку: [1, 2, "Hi"]. Но обычно в списке хранят однотипные вещи: только песни, только оценки. Так с ним проще работать в цикле.

Итог раздела

  • Список — значения по порядку в квадратных скобках.
  • Индексы, срезы, len() и in работают как у строк.
  • Список можно изменять: items[0] = значение.
2

Методы списка

Добавить, удалить, найти, отсортировать

У списка есть свои методы. На слайде лектора их одиннадцать, и все нужно знать. Важное отличие от строк: методы списка меняют сам список, а не создают новый.

МетодЧто делаетЧто возвращает
append(x)Добавляет x в конец.None
insert(i, x)Вставляет x на место с индексом i.None
extend(other)Добавляет в конец все элементы другого списка.None
remove(x)Удаляет первый элемент, равный x. Если такого нет — ошибка ValueError.None
pop(), pop(i)Удаляет последний элемент или элемент с индексом i.Удалённый элемент
index(x)Ищет x. Если такого нет — ошибка ValueError.Индекс первого найденного
count(x)Считает, сколько раз встречается x.Число
sort()Сортирует сам список по возрастанию.None
reverse()Переворачивает сам список.None
copy()Делает копию списка.Новый список
clear()Удаляет все элементы.None

Значение None в таблице значит «ничего»: метод сделал своё дело и ничего не вернул.

Тренажёр 1

Плейлист: методы списка

Впиши песню и индекс, нажимай кнопки. Следи, что стало со списком и что метод вернул. Попробуй удалить песню, которой нет.

sort() и sorted()

Отсортировать список можно двумя способами. Метод sort() меняет сам список. Функция sorted() список не трогает и возвращает новый, отсортированный.

Ловушка

Запись scores = scores.sort() уничтожает список: в переменной оказывается None. Правильно — либо scores.sort() отдельной строкой, либо ordered = sorted(scores).

Удаляем без ошибок

Методы remove() и index() останавливают программу, если элемента нет. Поэтому сначала проверяют оператором in.

Итог раздела

  • Методы списка меняют сам список. Большинство возвращает None.
  • pop() возвращает удалённый элемент, index() и count() — число.
  • sort() сортирует на месте, sorted() возвращает новый список.
  • Перед remove() и index() проверяем in.

Перебор и готовые функции

Среднее, медиана, отбор

По списку идут циклом for — так же, как по строке. Если нужен ещё и номер элемента, помогает функция enumerate(): она выдаёт пары «номер и элемент». Второй аргумент задаёт, с какого числа начать счёт.

Цикл for song in playlist только читает элементы. Чтобы их менять, нужен индекс: идём по номерам через range(len(...)).

Готовые функции

Сумму, наименьшее и наибольшее в прошлой теме мы искали циклом и накопителями. Для списков есть готовые функции.

ВыражениеРезультатПояснение
len(temps)5Сколько элементов.
sum(temps)75Сумма.
min(temps)7Наименьшее.
max(temps)30Наибольшее.
sum(temps) / len(temps)15.0Среднее: сумма, делённая на количество.
sorted(temps)[7, 7, 12, 19, 30]Новый отсортированный список.

Писать такие циклы самому всё равно нужно уметь: на контрольной могут попросить найти наибольшее без готовой функции.

Отбор, среднее и медиана

Частая задача: выбрать из списка элементы, которые подходят под условие. Приём такой: создаём пустой список и в цикле добавляем в него подходящие элементы.

Медиана — это значение, которое стоит в середине, если расставить числа по возрастанию. Когда чисел нечётное количество, середина одна: элемент с индексом len // 2. Когда чётное — берут среднее двух соседних: (ordered[middle - 1] + ordered[middle]) / 2.

Строка и список

split и join

Вводить десять чисел десятью вопросами неудобно. Проще ввести их одной строкой через пробел. Метод строки split() режет строку на части и возвращает список. Обратную работу делает метод join(): он склеивает список строк в одну строку.

ВыражениеРезультатПояснение
"мама мыла раму".split()['мама', 'мыла', 'раму']Без аргумента режет по пробелам.
"Мама мыла РАМУ".lower().split()['мама', 'мыла', 'раму']Сначала маленькие буквы, потом слова.
"12 7 30".split()['12', '7', '30']Внимание: получились строки, а не числа.
"хлеб,сыр,чай".split(",")['хлеб', 'сыр', 'чай']Можно резать по другому знаку.
" ".join(["мама", "мыла", "раму"])'мама мыла раму'Склеить через пробел.
"-".join(["2026", "11", "19"])'2026-11-19'Склеить через дефис.

Метод split() всегда выдаёт строки. Чтобы получить числа, каждую часть превращают через int() в цикле.

Итог раздела

  • split() режет строку на список строк, join() склеивает список строк.
  • Методы можно ставить цепочкой: text.lower().split().
  • Числа из строки: split(), потом int() для каждой части.

Кортежи

Записи, которые нельзя изменить

Кортеж похож на список, но его нельзя изменить. Пишут его в круглых скобках. Тип — tuple. Кортежем удобно хранить запись: несколько значений, которые вместе описывают одну вещь. Песня — это название, исполнитель и год.

Вторая строка с конца называется распаковкой. Слева столько имён, сколько значений в кортеже. Каждое имя получает своё значение. А вот изменить кортеж нельзя.

Список кортежей: набор записей

Самая полезная связка: каждая запись — кортеж, а все записи вместе — список. Записи не меняются, поэтому кортеж. Набор растёт и уменьшается, поэтому список.

Два приёма отсюда пригодятся постоянно. Первый — поиск «рекордной» записи: в накопителе лежит вся запись, а сравнивается одно её поле. Второй — поиск по части текста без учёта больших и маленьких букв: и запрос, и поле переводим в маленькие буквы.

Итог раздела

  • Кортеж — неизменяемый набор значений в круглых скобках.
  • Распаковка: title, artist = song.
  • Набор записей — это список кортежей.

Словарь

Значение по ключу

Словарь хранит пары «ключ и значение». Как в гардеробе: номерок — ключ, куртка — значение. По ключу значение находится сразу, без перебора. Ключи не повторяются. Словарь пишут в фигурных скобках, ключ и значение разделяют двоеточием. Тип — dict.

Одна и та же запись wardrobe[ключ] = значение и добавляет новую пару, и заменяет старое значение. Всё зависит от того, есть ли уже такой ключ.

Если прочитать значение по ключу, которого нет, программа остановится с ошибкой KeyError.

Защититься можно двумя способами. Первый — сначала проверить ключ оператором in. Второй — метод get(): он возвращает значение, а если ключа нет — запасной вариант, который указан вторым аргументом.

Тренажёр 3

Гардероб: словарь в действии

Впиши ключ и значение, нажимай кнопки. Попробуй прочитать и удалить ключ, которого нет.

Итог раздела

  • Словарь — пары «ключ: значение». Ключи уникальны.
  • d[k] = v добавляет или заменяет, del d[k] удаляет, k in d проверяет ключ.
  • Чтение по отсутствующему ключу — KeyError. Спасают in и get().

Перебор и подсчёт

Ключи, пары и счётчики

Цикл for по словарю идёт по его ключам. Если нужны сразу и ключ, и значение, берут метод items(): он выдаёт пары, и их удобно распаковать прямо в заголовке цикла.

Подсчёт: сколько раз встречается каждое значение

Словарь — готовый набор счётчиков. Ключ — то, что считаем. Значение — сколько раз это встретилось. Если ключа ещё нет, заводим его с единицей. Если есть — прибавляем один.

То же самое можно записать одной строкой через get(): counts[letter] = counts.get(letter, 0) + 1. Читается так: «возьми старое значение или ноль и прибавь один».

Вторая половина программы ищет ключ с самым большим значением. Приём знакомый: в переменной best лежит лучший ключ из уже просмотренных, и каждый новый ключ сравнивается с ним по значению. Буквы «ш» и «а» встречаются по два раза. Ключи перебираются по алфавиту, а знак сравнения строгий — >. Поэтому побеждает «а»: буква «ш» идёт позже и с тем же числом её не вытесняет. Без sorted() победила бы «ш», потому что она встретилась в слове первой.

Итог раздела

  • for k in d идёт по ключам, for k, v in d.items() — по парам.
  • Подсчёт: ключа нет — записываем 1, ключ есть — прибавляем 1.
  • Самый частый ключ: перебор по sorted() и строгое сравнение — при равенстве побеждает тот, что раньше по алфавиту.

Словарь записей

База по уникальному номеру

Настоящие данные устроены сложнее одной пары. У фильма есть название, год, несколько жанров и оценки зрителей. Для этого структуры вкладывают друг в друга. Самая частая схема на контрольной: словарь записей. Ключ — уникальный номер, значение — словарь с полями записи. Поле само может быть списком или словарём.

Запись movies[101]["title"] читается слева направо: сначала по номеру достаём запись, потом из записи по названию поля достаём значение. Если поле — список или словарь, его меняют прямо на месте: append() для списка, [ключ] = значение для словаря. Внутри f-строки для ключей берут одинарные кавычки, потому что двойные уже заняты.

Справочник и запись

Часто рядом с базой нужен ещё один словарь — справочник. Например, у каждого кружка свои дни занятий. В записи ребёнка хранится только название кружка, а дни берутся из справочника по этому названию.

Запись schedule[kid["club"]] читается изнутри наружу: сначала из записи берём название кружка, потом по нему из справочника — список дней. Цикл идёт по дням кружка, а не по посещениям. Поэтому выводятся и те дни, когда Оля ещё не была.

Итог раздела

  • Словарь записей: номер — ключ, запись — словарь с полями.
  • data[номер][поле] читается слева направо.
  • Поле-список и поле-словарь меняют на месте.
  • Справочник берут по значению поля записи: schedule[kid["club"]].

Практикум: библиотека

Собираем всё вместе

Пишем программу в виде задания с контрольной. Задание устроено так же, как вторая контрольная этого курса, только про книги.

  • a) Библиотека хранит книги. У книги есть уникальный номер ISBN, название, число свободных экземпляров и жанры — их может быть несколько. Нужно выбрать структуру данных для любого числа книг.
  • b) Меню: добавить книгу; выдать книгу, если есть свободный экземпляр; показать все книги.
  • c) Для каждой структуры данных обосновать в комментарии, почему выбрана именно она.

Проследи по выводу: книга «Сказки» одна, поэтому первая выдача проходит, а вторая — уже нет. Номер 000 программа отклоняет, не останавливаясь с ошибкой: ключ проверяется до обращения к словарю.

На КР

Три вещи, за которые здесь дают баллы. Первая: запись находится по уникальному номеру, и повторный номер отклоняется. Вторая: перед каждым обращением к словарю ключ проверяется. Третья: в пункте c) назван каждый вид структуры — и для набора записей, и для одной записи, и для поля с несколькими значениями.

Тренажёр 4

Охота на баги

В каждой программе одна ошибка. Щёлкни по строке, которую нужно исправить.

Программа должна вывести наименьшее число.

Traceback (most recent call last):
  File "smallest.py", line 3, in <module>
    print(numbers[0])
TypeError: 'NoneType' object is not subscriptable

Верно. Python остановился на строке 3, но причина — в строке 2. Метод sort() ничего не возвращает, и в переменную попал None. Нужно просто numbers.sort().

Программа должна вывести три напитка.

Traceback (most recent call last):
  File "drinks.py", line 3, in <module>
    print(items[i])
IndexError: list index out of range

Верно. В списке три элемента с индексами 0, 1 и 2. Из-за лишнего + 1 цикл доходит до индекса 3, которого нет. Нужно range(len(items)).

Программа должна исправить название песни.

Traceback (most recent call last):
  File "record.py", line 2, in <module>
    record[0] = "Faded"
TypeError: 'tuple' object does not support item assignment

Верно. Кортеж нельзя изменить. Нужно создать новый кортеж: record = ("Faded", record[1]).

Программа должна вывести цену или сообщить, что товара нет.

Traceback (most recent call last):
  File "price.py", line 2, in <module>
    print(prices["кофе"])
KeyError: 'кофе'

Верно. Ключа «кофе» в словаре нет, и чтение по нему даёт KeyError. Нужно сначала проверить if "кофе" in prices или взять prices.get("кофе", "нет такого товара").

Программа должна посчитать, сколько раз встречается каждое слово.

Traceback (most recent call last):
  File "words.py", line 3, in <module>
    counts[word] += 1
KeyError: 'да'

Верно. Когда слово встречается впервые, ключа в словаре ещё нет, и counts[word] += 1 даёт KeyError. Нужна проверка: ключа нет — записать 1, ключ есть — прибавить 1. Или одной строкой: counts[word] = counts.get(word, 0) + 1.

Итог раздела

  • Набор записей — словарь по уникальному номеру, запись — словарь полей.
  • Перед обращением по ключу проверяем in или not in.
  • Каждую выбранную структуру объясняем в комментарии.

Итоги лекции

Пять фактов и пять терминов

5 главных фактов

  1. Список хранит много значений по порядку и может меняться. Методы меняют сам список, sort() возвращает None.
  2. split() режет строку на список строк. Числа получают через int() для каждой части.
  3. Кортеж — неизменяемая запись. Набор записей — список кортежей.
  4. Словарь находит значение по ключу сразу. Перед чтением ключ проверяют через in или берут get().
  5. База записей — словарь по уникальному номеру, запись — словарь полей: data[номер][поле].

Проверь себя

Восемь вопросов

Сначала ответь сам — вслух или на бумаге. Потом открой ответ и честно отметь результат.

Что вернёт items.sort()? Что окажется в переменной после items = items.sort()?

Метод sort() сортирует сам список и возвращает None. После записи items = items.sort() в переменной лежит None, а список потерян.

Чем remove() отличается от pop()?

remove(x) удаляет элемент по значению и ничего не возвращает; если значения нет, будет ValueError. pop(i) удаляет элемент по индексу и возвращает его; без аргумента удаляет последний.

Что выдаст "12 7 30".split()? Можно ли сразу посчитать сумму через sum()?

Получится список строк ['12', '7', '30']. Сумму посчитать нельзя: будет TypeError, потому что это строки. Сначала каждую часть превращают через int().

Почему одного игрока удобно хранить кортежем, а всех игроков — списком?

Игрок — запись: имя и очки после ввода не меняются, и кортеж не даёт изменить их случайно. Набор игроков растёт по мере ввода — для этого нужен список.

Что случится при чтении prices["кофе"], если такого ключа нет? Как защититься?

Программа остановится с ошибкой KeyError. Защититься можно проверкой if "кофе" in prices перед чтением или методом get(): prices.get("кофе", 0) вернёт запасное значение.

Как посчитать, сколько раз встречается каждое слово? Что делать, когда слово встретилось впервые?

Завести пустой словарь: ключ — слово, значение — сколько раз. Если слова ещё нет среди ключей, записать 1, иначе прибавить 1. Короче: counts[word] = counts.get(word, 0) + 1.

Как прочитать название фильма с номером 101 из словаря movies? Как вывести его внутри f-строки?

movies[101]["title"]: сначала запись по номеру, потом поле по названию. В f-строке в двойных кавычках ключ пишут в одинарных: f"Фильм: {movies[101]['title']}".

В базе книг три структуры. Какие и почему каждая выбрана?

Все книги — словарь по ISBN: номер уникален, книга находится сразу, повтор номера невозможен. Одна книга — словарь полей: у полей понятные названия, число экземпляров меняется. Жанры — список: жанров может быть несколько, и их число заранее неизвестно.
